# Starter prompts — paste karne ke liye tayyar

Teen prompts, teen asli lamhe: pehla agent, jab wo toot jaaye, aur jab usay customer ke
saamne khara karna ho. Claude, Claude Code, GPT — teeno par chalte hain.

---

## 1. Pehla agent — khaali folder se

```
Main ek AI agent banana chahta hoon aur mujhe coding ka tajurba nahi hai.

Kaam: <ek jumla likhein — jaise "meri Gmail inbox se un emails ki list banaye
jin ka jawab dena reh gaya hai">

Mujh se poochho:
1. Kaun se tools is kaam ke liye zaroori hain
2. Sab se chhota pehla version kya hoga jo chal kar dikhaye

Phir ek-ek qadam mein chalo. Har qadam ke baad ruk kar batao ke main apni screen
par kya dekhna chahiye. Agar main "nahi dikha" kahoon to aage na barho.

Ek shart: koi API key file mein na likho. Hamesha environment variable.
```

## 2. Jab agent toot jaaye

```
Mera agent chal nahi raha. Neeche error hai.

<error paste karein>

Mujhe teen cheezein batao, isi tarteeb mein:
1. Error asal mein kya keh raha hai — aam Urdu mein
2. Sab se mumkin wajah, aur usay check karne ka ek tareeqa
3. Ek choti tabdeeli jo iska imtihaan kar de

Poora code dobara na likho. Mujhe samajhna hai ke toota kahan.
```

## 3. Customer ke saamne khara karne se pehle

```
Yeh mere AI Employee ka system prompt hai. Isay customers ke saamne lagana hai.

<prompt paste karein>

Ek sakht reviewer ban kar batao:
1. Kaun sa sawal aisa hai jis par yeh ghalat jawab dega
2. Kahan yeh koi aisa waada kar sakta hai jo company poora na kar sake
3. Kaun si baat prompt mein likhi hai jo tool se aani chahiye thi
4. Kaun se mod par insaan ko bulana chahiye lekin likha nahi hai

Har masle par ek jumla, aur ek theek karne wala jumla. Taareef na karo.
```

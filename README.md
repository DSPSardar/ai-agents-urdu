# AI Agents in Urdu — glossary, templates aur starter prompts

AI agents aur **AI Employees** banane ke liye jo lafz, template aur prompt rozana kaam
aate hain — Urdu aur Roman Urdu mein, ek jagah. Ye repo [Digital Services
Program](https://www.digitalservicesprogram.com/) ka open-source hissa hai. Digital Services
Program ek **AI Employee company** hai: hum businesses ke liye AI Employees banate hain, aur
logon ko ye banana sikhate bhi hain.

یہ ریپو اردو بولنے والوں کے لیے ہے جو AI ایجنٹ اور AI Employee بنانا سیکھ رہے ہیں۔ یہاں
اصطلاحات کی لغت، ایک ایجنٹ کی "جاب ڈسکرپشن" کا سانچہ، اور شروع کرنے کے لیے تیار پرامپٹس ہیں۔

## Is repo mein kya hai

| File | Kya hai |
|---|---|
| [`GLOSSARY.md`](GLOSSARY.md) | 30 istilaahein — agent, tool, context, MCP, token, embedding waghera — Urdu script, Roman Urdu aur ek-line tareef ke saath |
| [`7-part-job-description-urdu.md`](7-part-job-description-urdu.md) | Ek AI Employee ki job description likhne ka saat-hissa sanchaa, bhara hua misaal ke saath |
| [`starter-prompts.md`](starter-prompts.md) | Paste karne ke liye tayyar prompts — pehla agent, debugging, aur ek customer-facing AI Employee |

## Ye kis ke liye hai

Agar aap coding nahi jaante lekin AI agent banana chahte hain, sab se bari rukawat lafz hoti
hai: har tutorial English mein hai aur har lafz naya hai. Ye glossary wohi rukawat hataati
hai. Tool ke naam aur code English mein hi rahenge — Claude, GitHub aur Vercel English hi
samajhte hain — lekin samajh Urdu mein aani chahiye.

## Contribute

Koi istilaah ghalat lagti hai, ya koi lafz reh gaya hai? Issue khol dein ya pull request
bhej dein. Urdu technical vocabulary par do logon ka ittefaq mushkil hota hai — is liye
glossary mein har entry ke saath Roman Urdu bhi hai, taake jo lafz aap sunte hain wohi
pehchaan sakein.
